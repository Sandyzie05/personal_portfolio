## Dependency Decisions (deviations from `01-UI-SPEC.md`'s suggestions, documented per scope-reduction-prohibition — these are substitutions, not scope cuts)

- **Icons:** `01-UI-SPEC.md` suggests `lucide-react`, but `01-RESEARCH.md`'s Package Legitimacy Audit does not cover it. Rather than expanding the audit for one package, use hand-authored inline SVG icons (hamburger, external-link glyph, mail/LinkedIn/GitHub glyphs) — visually equivalent, zero new dependency.
- **Fonts:** Use Google Fonts CDN `<link>` tags for Inter + JetBrains Mono (weights 400/700 only, matching `01-UI-SPEC.md`'s typography tokens) instead of `@fontsource/*` packages — avoids adding unaudited npm packages; this is a client-side browser fetch, unrelated to the CloudLinux runtime constraint (that constraint is about the Node *server* process, not the visitor's browser).
- **Framer Motion:** `01-RESEARCH.md` marks it optional for this phase. Phase 1's only micro-interactions (nav-link hover/focus states, project-card hover glow in Plan 03) are fully achievable with CSS `:hover`/`:focus-visible`/`transition`. Omitted from `package.json` for Phase 1 — CLAUDE.md's Phase 3 stack plan (theme picker/opacity slider) is where Framer Motion earns its weight.
- **jest-dom:** Not in `01-RESEARCH.md`'s audit table. Tests use `@testing-library/react`'s `render`/`screen` plus Vitest's native `expect(...).toBeTruthy()` / `.toBe(...)` — no extended matchers needed.

Net effect: this phase's `package.json` dependency set is `react`, `react-dom` (deps) + `vite`, `@vitejs/plugin-react`, `typescript`, `eslint`, `@eslint/js`, `typescript-eslint`, `eslint-plugin-react-hooks`, `eslint-plugin-react-refresh`, `globals`, `@types/react`, `@types/react-dom`, `vitest`, `jsdom`, `@testing-library/react` (devDeps) — every one of these 16 packages appears in `01-RESEARCH.md`'s Package Legitimacy Audit table. Zero unaudited packages are introduced.
